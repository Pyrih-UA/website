# Національний конкурс пирогів

Next.js starter for the competition website.

## Getting started

Install dependencies with `npm install`, then run `npm run dev` and open http://localhost:3000.

## Content to add

Replace the placeholder copy with competition details, partner logos, jury information, photos and recipes. Update the contact section and footer with the real contact details. The countdown component is in `src/components/home/Countdown.tsx`; set the official date and add it to the homepage when the date is confirmed. The recipe detail route currently returns a 404 until recipes are added.
